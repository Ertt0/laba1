# Лабораторная работа №1

## Введение
Написать Python-пакет, в котором будет калькулятор арифметических выражений и конвертер единиц измерения массы, длины и температуры.


## Калькулятор

Поддерживает:
- целые и вещественные числа;
- операции '+', '-', '*', '/';
- унарные '+' и '-';
- пробелы между токенами игнорируются;
- приоритет операций '*', '/' над '+', '-'.

Вычисление выражений выполняется без использования eval, exec, ast.literal_eval и других инструментов парсинга.

## Конвертер

Поддерживаются следующие единицы:
- длина (mm, cm, m, km)
- масса (g, kg)
- температура (c, f, k)

Поддерживается любой регистр единиц.
Конвертация разных групп единиц запрещена. Температура не может быть ниже абсолютного нуля.

## Запуск

Для запуска используется uv

## Справка

uv run python -m toolkit --help

## Калькулятор

uv run python -m toolkit calc "2 + 3 * 4"

## Конвертер

uv run python -m toolkit convert 5 --from km --to m

## Обработка ошибок

При возникновении ошибки программа выводит сообщение в stderr и завершает работу с кодом 2.

Обрабатываются ошибки:
- пустое выражение;
- неизвестные символы;
- отстутствие операнда;
- некорректная последовательность операторов;
- деление на ноль;
- неизвестная единица измерения;
- несовместимые единицы измерения;
- значение температуры ниже абсолютного нуля.

## Тестирование

Для запуска тестов используется pytest:

uv run pytest

Тесты проверяют:
- токенизацию выражений;
- валидацию выражений;
- вычисление арифметических выражений;
- унарные операторы;
- деление на ноль;
- конвертацию длины, массы и температуры;
- регистр единиц измерения;
- несовместимые единицы;
- неизвестные единицы;
- абсолютный ноль;
- ошибочные входные данные.

## Проверка качества кода

Для проверки качества кода используются ruff и mypy:

uv run ruff check .

uv run mypy src/

Также настроен pre-commit:

uv run pre-commit run --all-files

Все проверки завершаются успешно.
